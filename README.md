## Products

- **[Firstline-ai](https://firstline-ai.site)**. A cold email tool I designed, built and launched. Upload a prospect list and it researches each company's website and LinkedIn profile, then writes three scored opening lines per prospect and picks the strongest. Users bring their own API key from any LLM provider and choose the model. Next.js, FastAPI, Python, PostgreSQL.
- **[KMB-Talk](https://kmb-talk.com)**. A bookkeeping app for traders who buy and sell on credit: stock, sales, supplier debt and customer receivables in one book, in francs and dollars, with an offline queue for weak connections. It began as a public repository of mine. When I heard a trader had exactly this problem, I showed it to him, then adapted it to his business, internationalized it and added a mobile app. It is now his private product, used every day by him and his employees, so the link opens a test environment. NestJS, PostgreSQL, Next.js, React Native.
